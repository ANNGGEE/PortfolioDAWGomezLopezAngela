# Índice de trabajos - UD3: Apache
## Trabajos de la unidad: 
### 1. **Apache: Introducción y Apache: Configuración**

En este trabajo se han realizado dos prácticas relacionadas con Apache HTTP Server. 

En la primera actividad se ha trabajado la parte introductoria y documental del proyecto, elaborando una memoria en la que se explica qué es Apache, su historia, sus principales características, las alternativas existentes y la motivación para utilizarlo.

En la segunda práctica se ha llevado a cabo la parte práctica, instalando y configurando un servidor web Apache en un entorno Ubuntu Server mediante una máquina virtual. Para ello, se ha creado una página web personalizada utilizando HTML y CSS, se ha configurado un Virtual Host y se ha incorporado un sistema de autenticación básica mediante usuario y contraseña para restringir el acceso a la página.

Además, se han realizado diferentes pruebas desde el navegador, mediante comandos de terminal y desde otro equipo de la red, con el objetivo de comprobar el funcionamiento del servidor y las medidas de control de acceso implementadas.

De esta manera, ambas actividades permiten combinar la documentación teórica sobre Apache con su instalación, configuración y administración en un entorno práctico.

[Apache introducción y Configuración Gómez López Ángela.pdf](https://github.com/user-attachments/files/35286876/Apache.introduccion.y.Configuracion.Gomez.Lopez.Angela.pdf)

### 2. **Apache: HTTPS**

En esta práctica se ha investigado e implementado el protocolo HTTPS en un servidor web Apache2 ejecutado sobre Ubuntu.

En primer lugar, se ha elaborado una memoria teórica en la que se explica el funcionamiento de HTTPS, su importancia para la seguridad de las comunicaciones web y las diferencias entre los certificados autofirmados y los emitidos por autoridades certificadoras de confianza.

En la parte práctica se ha configurado Apache2 para permitir conexiones seguras mediante HTTPS. Para ello, se han habilitado los módulos SSL y headers, se ha generado un certificado autofirmado utilizando OpenSSL y se ha configurado un VirtualHost para escuchar en el puerto 443.

Además, se ha establecido una redirección automática de HTTP a HTTPS y se han realizado diferentes comprobaciones mediante curl, OpenSSL y Firefox para verificar el funcionamiento de la conexión segura.

Esta práctica ha permitido comprender cómo se implementa HTTPS en un servidor web y conocer la importancia de los certificados digitales para proteger la información transmitida entre clientes y servidores.
