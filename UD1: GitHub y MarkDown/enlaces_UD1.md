# Índice de trabajos - UD1: GitHub y MarkDown
## Trabajos de la unidad: 
### 1. **GitHub: Introducción**
En este trabajo vamos a ver las _funcionalidades más básicas de GitHub_, como puede ser, la creación de un repositorio, un archivo, _commit changes_... a cosas más avanzadas como puede ser la creación y administración 
de _ramas_, sus modificaciones, _merges_, _new pull request_, _create pull request_, _merge pull request_ o la configuración del repositorio y sus permisos.

### 2. **Markdown**
En esta práctica se utiliza Markdown para crear un documento lo más parecido posible al pdf que se nos da en el enunciado. Para conseguirlo, se ponen en práctica diferentes opciones de formato, como títulos, negritas, cursivas, imágenes y enlaces, intentando respetar la estructura y el diseño del documento original.
Con esta actividad aprendemos a utilizar mejor Markdown y a conocer sus posibilidades para crear y organizar documentos de forma sencilla.

### 3. **GitHub + MarkDown**
En esta práctica se presentan los principales usos de GitHub y se explican, paso a paso, algunas de sus funciones más importantes, como la creación de repositorios, la subida de archivos, el uso de ramas, las pull requests, la gestión de incidencias y la publicación de páginas web. Asimismo, se introduce GitHub Actions, una herramienta que permite automatizar tareas mediante flujos de trabajo. Finalmente, se incluyen unas conclusiones sobre la utilidad de esta plataforma y los conocimientos adquiridos.
